# 🤝 SkillSwap

### Share What You Know. Learn What You Love.

## 📌 About the Project

SkillSwap is a student skill-sharing platform that helps students connect with learning partners. Students can share the skills they can teach, list the skills they want to learn, and discover potential learning partners based on their skills and preferences.

## ✨ Features

* **Create Profile:** Add your details, skills, and learning preferences.
* **Teach & Learn:** List the skills you can teach and want to learn.
* **Partner Preferences:** Select your preferred learning speed, style, availability, and learning mode.
* **Smart Recommendations:** Discover potential learning partners based on matching skills.
* **Compatibility Score:** View a score to help compare potential matches.
* **Local Data Storage:** Save student profiles locally.

## 🛠️ Technologies Used

* Python
* Streamlit
* JSON for local data storage

## 🚀 How to Run the Project

1. Install Python on your computer.

2. Install Streamlit:

   ```bash
   py -m pip install streamlit
   ```

3. Open the project folder in VS Code.

4. Open the terminal and run:

   ```bash
   py -m streamlit run app.py
   ```

5. Open the local URL shown in the terminal.

## 📂 Project Structure

* `app.py` — Main application code
* `run_skillswap.bat` — Windows launcher for the application
* `skillswap_data.json` — Local profile data, generated when profiles are saved

## 🎯 Project Goal

To encourage peer-to-peer learning by helping students exchange knowledge, discover new skills, and learn collaboratively.
